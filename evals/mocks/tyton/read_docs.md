Tyton guidance for {{input.topic}}.

Pixel step: Open Events Manager (https://business.facebook.com/events_manager2/), choose your website's dataset, then open Settings. Copy the numeric Dataset ID into Tyton's Pixel field. Check it is not a Page, business or ad account ID. If you don't have a dataset yet, choose Connect data, then Web, then Next, and follow the prompts.

Token step: In the dataset, go to Settings, then Conversions API, and choose Generate access token. Paste it into Tyton's secure Conversions API token field, or use the Tyton browser extension to get a sealed token.
